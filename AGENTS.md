# Руководство для агентов

Документ служит точкой входа для ИИ-агентов и разработчиков. Технические детали вынесены в специализированные файлы, здесь остаётся индекс и рабочие договорённости.

## TL;DR

- Работай через таск-трекер `bd`.
- Перед завершением сессии следуй чек-листу «Landing the Plane».
- Используй разделы ниже как каталог.

## Рабочий процесс агента

1. Синхронизируйся с задачей: проверь актуальные issues и обнови состояние в `bd`.
2. Определи нужные разделы документации по таблице выше.
3. При изменениях кода запускай тесты и линтеры согласно [`runbook.md`](docs/operations/runbook.md:1).
4. Завершая сессию, выполняй чек-лист из [`landing-plane.md`](docs/operations/landing-plane.md:1).

## Коммуникация и beslutки

- Все новые правила фиксируй в соответствующих файлах документации.
- Если появляются открытые вопросы, создавай issue и оставляй заметку в `bd`.
- При расхождениях между кодом и документацией приоритет у фактической реализации; обнови документацию.
