# Завершение рабочей сессии (Landing the Plane)

**Завершая сессию**, необходимо выполнить все шаги ниже. Работа считается завершённой только после успешного `git push`.

## Обязательный порядок действий

1. **Заведи задачи на оставшуюся работу** — зафиксируй всё, что требуется сделать позже.
2. **Запусти quality-gates** (если менялся код) — тесты, линтеры, сборки.
3. **Обнови статусы задач** — закрой завершённые, обнови «в работе».
4. **Выполни push в remote**:

   ```bash
   git pull --rebase
   bd sync
   git push
   git status  # должен показать "up to date with origin"
   ```

5. **Очисти рабочее окружение** — убери стэши, почисти удалённые ветки.
6. **Проверь** — все изменения закоммичены и запушены.
7. **Хэнд-офф** — опиши контекст или следующий шаг для следующей сессии.

## Критические правила

- Работа незавершена, пока `git push` не выполнен.
- Нельзя останавливаться до пуша — иначе изменения останутся локально.
- Не используй формулировки «готов к пушу» — пуш выполняешь ты.
- При ошибках пуша обязательна отладка и повторная попытка.
